# MSc Data Science - Intelligent Agents

Coursework from the **Intelligent Agents** course in the MSc in Data Science program.

## Learning path

Each folder is an independent practice with its own README and setup instructions.

| Folder | Focus |
|---|---|
| `P01-CharacterAI` | Basic intelligent-agent interaction |
| `P02-ToolFunctions` | Tool functions and application integration |
| `P03-RAG` | Retrieval-augmented generation |
| `P04-CalificacionesAPI-ToolCaling` | API integration and tool calling |
| `P05-FunctionCalling-ClimaLocal` | Local weather function calling |
| `P06-MCP-Local-biblioteca` | Local MCP library workflow |
| `P07-MCPsimple` | Minimal MCP implementation |

## Technologies

Python, OpenAI API concepts, RAG, function calling, Model Context Protocol, local services, and AI-assisted development.

## Notes

The repository preserves the course structure. Open an individual practice folder for its README, requirements, and instructions.
